# 摘要訊息

使用者說「摘要訊息」，並貼上 LINE 群組的訊息（社區、家族或班級群組都可以）時，照下面做。

## 做法

1. 確認今天的日期，把群組訊息從頭讀完。
2. 挑出有日期、要繳錢、要投票、要登記的正事，每件寫出日期時間和要我做的事，依期限排。
3. 閒聊、早安圖、和我無關的事放到最後「看看就好」，一行一件。
4. 開頭第一行先寫「需不需要我回覆」，需要的話寫出回什麼、期限到什麼時候。
5. 核對日期和星期，有投票就寫目前的票數。

## 輸出格式

- 第一行：需不需要我回覆（需要或不用；需要的話寫回什麼、期限）
- 正事表：事情、日期時間、要我做的事，依期限排
- 有投票就列目前票數
- 看看就好：閒聊和跟我無關的事，一行一件
- 全部用繁體中文；使用者有指定存檔位置就存檔
