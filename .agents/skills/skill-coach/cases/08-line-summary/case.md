# 案例 08｜LINE 群組長訊息摘要

- 情境：社區群組和家族群組一天幾十則，重要的事混在早安圖和閒聊裡，常常漏看要回覆的事。
- 三格檢查：每隔幾天就要看 ✓／步驟固定 ✓／好壞看得出來（該回的有抓到、日期沒錯、閒聊被濾掉）✓
- 素材：`素材-1.md`（社區群組這幾天的訊息）、`素材-2.md`（家族群組的訊息，開新聊天時用）
- 先做一次（3-2）：`請讀 我的練習/素材-1.md，幫我摘要這個群組的訊息，列出重要的事、日期時間和要我做的事，閒聊放最後一行帶過就好，存成 我的練習/成品-1.md。`
- 改一處建議（3-3）：`開頭第一行先寫「需不需要我回覆」。`
- 觸發語建議：摘要訊息
- 技能代號建議：line-summary
- 習慣建議（3-7）：附一句可以直接貼回群組的回覆。
- 過關時看：停水、監視器投票、住戶大會三件事都有，日期時間對，柿子、找貓、早安圖沒混進正事；改過之後第一行就看得到「需要回覆」和期限 10/18（日）晚上 10 點。
- 跳過時放的參考檔：`參考-成品.md`（已含第一行回覆那條）、`參考-工作流.md`、`參考-SKILL.md`
