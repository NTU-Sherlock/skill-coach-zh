# 排送禮清單

使用者說「排送禮清單」，並給要送的人（喜好、身體狀況、去年送過什麼、親送或宅配）時，照下面做。

## 做法

1. 讀要送的人：每個人的喜好、身體狀況、去年送過什麼、要親送還是宅配。
2. 每個人挑一樣禮物，避開身體不適合的和去年送過的。
3. 總預算不超過 8,000 元，每人一行寫出金額。
4. 寫出每份怎麼送，宅配的要提早寄。
5. 算合計，超過就先換便宜一點的禮物，最後列採買時間。

## 輸出格式

- 清單表：送給誰、送什麼、金額、怎麼送，每人一行
- 最後一列寫合計，和 8,000 元比一下
- 採買時間：宅配的先寄，其他的依時間列出
- 全部用繁體中文；使用者有指定存檔位置就存檔
