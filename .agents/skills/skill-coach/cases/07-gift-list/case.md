# 案例 07｜過年送禮清單

- 情境：每年過年要送家人、老師、鄰居，常常拖到最後一刻才去買，買完才發現花太多。
- 三格檢查：每年過年、中秋都要 ✓／步驟固定 ✓／好壞看得出來（每個人都有、送得合適、沒超預算）✓
- 素材：`素材-1.md`（今年過年要送的人）、`素材-2.md`（中秋節要送的人，開新聊天時用）
- 先做一次（3-2）：`請讀 我的練習/素材-1.md，幫我排過年送禮清單，每個人寫出送什麼、大概多少錢、親送還是宅配，存成 我的練習/成品-1.md。`
- 改一處建議（3-3）：`總預算不超過 8,000 元，每人一行寫出金額。`
- 觸發語建議：排送禮清單
- 技能代號建議：gift-list
- 習慣建議（3-7）：每人加一句「卡片上寫的話」。
- 過關時看：9 個人都有、爸爸的禮物照顧到血壓、媽媽今年沒再收到茶葉、台中那份寫宅配；改過之後每人一行有金額，合計 7,400 元，在 8,000 元以內。
- 跳過時放的參考檔：`參考-成品.md`（已含 8,000 元那條）、`參考-工作流.md`、`參考-SKILL.md`
