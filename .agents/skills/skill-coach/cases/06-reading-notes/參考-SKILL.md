# 整理讀書筆記

使用者說「整理讀書筆記」，並給書名、畫線的句子和頁碼（有寫心得也一起給）時，照下面做。

## 做法

1. 讀畫線的句子、頁碼和我的心得。
2. 先寫一句話說這本書在講什麼。
3. 每段畫線整理成一個重點，附上頁碼。
4. 每個重點不超過 30 字。
5. 從重點挑出馬上能做的事，寫成「我可以馬上試的」，我的心得照原文保留。

## 輸出格式

- 一句話說這本書
- 重點表：頁碼、重點（每個 30 字內）
- 我可以馬上試的：2 到 3 件，寫出什麼時候做
- 我的心得：照使用者寫的原文放進來
- 全部用繁體中文；使用者有指定存檔位置就存檔
