# 幫我記帳

使用者說「幫我記帳」，並給一週的發票、收據或刷卡紀錄時，照下面做。

## 做法

1. 讀這週的發票、收據和刷卡紀錄，一筆一筆列出日期、店家、品項、金額。
2. 分類固定 6 類：餐飲、交通、日用品、孩子、娛樂、其他，不能自己加新類別。
3. 每一筆放進一類，找不到合適的就放「其他」。
4. 算每一類的筆數和小計，再算這週總額和刷卡合計。
5. 核對：小計加起來要等於總額，筆數要等於紀錄的筆數。

## 輸出格式

- 小計表：類別、筆數、小計，最後一列是這週總額
- 明細：依類別分組，每筆寫日期、店家、品項、金額
- 備註：放進「其他」的項目說明一下，再寫刷卡筆數和合計
- 全部用繁體中文；使用者有指定存檔位置就存檔
