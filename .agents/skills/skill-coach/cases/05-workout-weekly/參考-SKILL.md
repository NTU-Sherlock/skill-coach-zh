# 寫運動週報

使用者說「寫運動週報」，並給一週的運動紀錄（目標、每天運動、體重、睡眠、下週行程）時，照下面做。

## 做法

1. 讀這週的運動紀錄、目標、體重、睡眠和下週行程。
2. 算數字：30 分鐘以上的次數、跑步總距離、總運動時間、體重變化，和目標對照。
3. 每天一行列出運動、時間、算不算達標。
4. 寫做得好的和要注意的，有痠痛或睡太少就寫出來。
5. 下週建議最多 3 條，每條 15 字內，要配合下週行程。

## 輸出格式

- 這週數字表：項目、目標、實際、結果
- 每天紀錄表：日期、運動、時間、算不算達標
- 做得好的、要注意的，各 2 到 3 點
- 下週建議：編號列出，最多 3 條，每條 15 字內
- 全部用繁體中文；使用者有指定存檔位置就存檔
