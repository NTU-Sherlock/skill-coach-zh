# 案例 02｜家庭小旅行行程表

- 情境：全家要出去玩 3 天 2 夜，每次都要查景點、排時間、算花費。家裡有長輩和小孩，排太滿大家都累。
- 三格檢查：每次出去玩都要排 ✓／步驟固定 ✓／好壞看得出來（時間排得下、長輩走得動、預算內）✓
- 素材：`素材-1.md`（這次去台南的狀況）、`素材-2.md`（下次去宜蘭的狀況，開新聊天時用）
- 先做一次（3-2）：`請讀 我的練習/素材-1.md，幫我排 3 天 2 夜的行程表，每天寫出時間、去哪裡、吃什麼，最後附吃和門票的預算估計，存成 我的練習/成品-1.md。`
- 改一處建議（3-3）：`每天下午留一段 1 小時休息，這段時間不排景點。`
- 觸發語建議：排行程
- 技能代號建議：trip-plan
- 習慣建議（3-7）：結尾附一段「下雨天備案」。
- 過關時看：三天都有時間表、第三天趕得上下午 5 點左右的高鐵、阿嬤要走路的地方標出時間、兒子想坐船看螃蟹有排到、預算估計在 6,000 元內；改過之後每天下午都有 1 小時休息，那段沒有景點。
- 跳過時放的參考檔：`參考-成品.md`（已含下午休息那條）、`參考-工作流.md`、`參考-SKILL.md`
