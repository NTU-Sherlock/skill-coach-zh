# 排行程

使用者說「排行程」，並給旅行狀況（日期、人數、誰走不久、交通、住宿、預算、想去的地方）時，照下面做。

## 做法

1. 讀旅行狀況：日期、幾個人、誰走不久、交通、住宿入住退房時間、預算、大家想去的地方。
2. 先放固定的事：去程和回程的班次、入住和退房時間。
3. 每天下午留一段 1 小時休息，不排景點。
4. 把想去的地方依距離排進每一天，順路的放同一天，長輩要走路的地方標出走路時間。
5. 估吃和門票的花費，確認在預算內，回程時間也要趕得上。

## 輸出格式

- 每天一張表：時間、要做什麼、備註（走路多久、車程多久）
- 下午的 1 小時休息寫進表裡，標出「不排景點」
- 最後一張預算表：每一項的估計、合計，和預算比一下
- 全部用繁體中文；使用者有指定存檔位置就存檔
