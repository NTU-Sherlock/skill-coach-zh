# 排菜單

使用者說「排菜單」，並給家裡狀況（人數、不吃的食材、冰箱存貨、預算、不用煮的日子）時，照下面做。

## 做法

1. 讀家裡狀況：幾個人、誰不吃什麼、冰箱剩什麼、預算、哪天不用煮。
2. 先用掉冰箱裡的食材，排週一到週五的晚餐，每天一主菜、一配菜、一湯。
3. 平日晚餐備料加烹調一律 30 分鐘內，每道菜標出分鐘數。
4. 列採買清單，依超市區域分類，扣掉冰箱已經有的。
5. 估總價，確認在預算內；不吃的食材一樣都不能出現。

## 輸出格式

- 菜單表：日期、主菜、配菜、湯、分鐘、先用掉冰箱的
- 採買清單：依區域分（肉和海鮮、蔬菜、豆製品和其他）
- 最後一行寫預算估計
- 全部用繁體中文；使用者有指定存檔位置就存檔
