# 案例 04｜孩子學校通知整理

- 情境：聯絡簿寫一點、班群又傳一堆，日期有的寫「下週三」、有的寫「16 號」，每天晚上都要對一次，常常漏掉。
- 三格檢查：每天或每週都有 ✓／步驟固定 ✓／好壞看得出來（沒漏事、日期和星期對、該帶的有寫）✓
- 素材：`素材-1.md`（這週的聯絡簿和班群訊息）、`素材-2.md`（下週的，開新聊天時用）
- 先做一次（3-2）：`請讀 我的練習/素材-1.md，幫我整理成一份通知清單，每件事寫出日期、要做什麼、要帶什麼，存成 我的練習/成品-1.md。`
- 改一處建議（3-3）：`依日期排序，日期一律寫成 10/14（三）這種格式。`
- 觸發語建議：整理通知
- 技能代號建議：school-notice
- 習慣建議（3-7）：最後列「今晚要準備的東西」。
- 過關時看：11 件事都有列到、家長在班群問的問題沒混進清單；改過之後依日期排好，「明天」「下週三」「16 號」都換成 10/13（二）、10/21（三）、10/16（五）這種寫法，星期也對。
- 跳過時放的參考檔：`參考-成品.md`（已含日期格式那條）、`參考-工作流.md`、`參考-SKILL.md`
