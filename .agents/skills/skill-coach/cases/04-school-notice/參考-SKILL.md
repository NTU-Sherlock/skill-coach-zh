# 整理通知

使用者說「整理通知」，並貼上聯絡簿、班群訊息或學校通知時，照下面做。

## 做法

1. 先確認今天的日期和星期，把「明天」「下週三」「16 號」這類寫法換算成實際日期。
2. 讀聯絡簿和班群，挑出老師和家長會交代的事，家長之間的提問和閒聊不列。
3. 每件事寫出要做什麼、要帶什麼、截止時間。
4. 依日期排序，日期一律寫成 10/14（三）這種格式。
5. 核對星期有沒有寫錯，同一件事出現兩次就合併成一行。

## 輸出格式

- 一張表：日期、事情、要做什麼／要帶什麼、來源（聯絡簿或班群）
- 有截止日的事，日期後面加「前」，例如 10/14（三）前
- 表格下面寫日期換算，讓人對得回原本的寫法
- 全部用繁體中文；使用者有指定存檔位置就存檔
