# 練習進度.md 範本

開始練習時，在專案資料夾建 `練習進度.md`，內容照下面（時間用 `date '+%Y-%m-%d %H:%M'` 取）。

```markdown
# 練習進度

- 目前位置：1-1
- 狀態：進行中
- 經驗值：0
- 稱號：技能新手
- 技能存放位置：Codex 技能資料夾
- 最後更新：YYYY-MM-DD HH:MM

## 我的技能

- 案例：（3-1 填）
- 我改過的地方：（3-3 填，寫學員原話）
- 觸發語：（3-5 填）
- 技能代號：（3-5 填）
- 技能檔位置：（3-5 填完整路徑）
- 加的習慣：（3-7 填）

## 關卡

### 第一章｜什麼是 skill
- [ ] 1-1 哪一個最像 skill
- [ ] 1-2 新聊天叫得出技能嗎

### 第二章｜什麼時候該做成 skill
- [ ] 2-1 六個情境判斷

### 第三章｜用 skill-creator 打造
- [ ] 3-1 選一個生活任務
- [ ] 3-2 先手動做一次
- [ ] 3-3 改到滿意
- [ ] 3-4 請它寫下步驟
- [ ] 3-5 用 skill-creator 做成繁體中文技能
- [ ] 3-6 開新聊天叫出它
- [ ] 3-7 加一條自己的習慣 v2
- [ ] 3-8 自由關：做第二個自己的技能

## 獎勵

（章節完成時加一行，例：- 第一章完成 +20）
```

## 寫法

- 打勾時在後面加結果與分數：`- [x] 1-1 哪一個最像 skill｜過關 +10`、`- [x] 3-2 先手動做一次｜跳過 +0，放了 我的練習/成品-1.md（參考版）`。
- 經驗值＝這個檔案裡所有「+數字」的加總。
- 狀態只有四種：進行中、暫停、自己玩、完成。
