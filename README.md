# 打造你的第一個 skill｜互動教練

在 Codex 說一句「開始練習」，教練會一步一步陪你，把生活裡重複的小事做成自己的技能（skill）。

## 你需要

- 電腦版 ChatGPT，能打開 Codex。
- 大約 30 分鐘。可以分幾次做，進度會記在資料夾裡。

## 三步開始

1. 下載：按這頁綠色的「Code」→「Download ZIP」，解壓縮。不用登入。
2. 打開：在 ChatGPT 桌面版的 Codex 開新專案，選剛剛解壓縮的資料夾。
3. 開練：送出「開始練習」。

教練會先說今天要做出什麼，接著出第一題。

## 你會做什麼

| 章 | 內容 | 做完你會 |
|---|---|---|
| 一 | 什麼是 skill，兩題小測驗 | 用食譜卡說得出 skill 是什麼 |
| 二 | 什麼事值得做成 skill，六個生活情境 | 會挑出值得做的事 |
| 三 | 用 skill-creator 動手做 | 有一個開新聊天也叫得出來的技能，再加一條你自己的習慣 |
| 自由關 | 拿你自己的事再做一個 | 兩個技能 |

## 8 個生活案例（也可以用自己的事）

1. 每週排晚餐菜單和採買清單
2. 全家 3 天 2 夜小旅行行程表
3. 一週發票和刷卡紀錄分類記帳
4. 孩子聯絡簿和班群通知整理成清單
5. 一週運動紀錄寫成週報
6. 讀書畫線整理成讀書筆記
7. 過年送禮清單
8. LINE 群組一大串訊息摘要

練習素材都是編的，沒有真實的人。

## 隨時可以說

| 你說 | 教練會 |
|---|---|
| 提示 | 給一點提示，一次一層 |
| 跳過 | 放一份參考成品給你，下一關照樣能做 |
| 暫停 | 記下進度 |
| 繼續練習 | 從上次的地方接著做。開新聊天時要講完整的「繼續練習」，只說「繼續」叫不出教練 |
| 目前進度 | 看經驗值、稱號和下一步 |
| 我先自己玩 | 先不評分，想問什麼都可以；說「回來」接著練 |

## 小提醒

- 做成技能時會跳出權限請求，按允許。
- 共用電腦：一開始跟教練說「這台是共用電腦」，技能就只存在這個資料夾，刪掉資料夾就清乾淨。
- 用自己的事練習時，真名、電話、帳號先換成代稱。
- 進度記在「練習進度.md」，練習檔放在「我的練習」。
- 資料夾裡的 `.agents` 是教練本人。它是隱藏資料夾，在 Finder 看不到是正常的，不要刪。
